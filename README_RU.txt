BUSIK — Android WebView project

В проект уже встроена игра в app/src/main/assets/index.html.
APK собирается GitHub Actions автоматически после загрузки проекта в репозиторий.

Шаги:
1. Распакуйте этот ZIP.
2. Загрузите ВСЁ СОДЕРЖИМОЕ папки Busik_Android в корень пустого GitHub-репозитория (не сам ZIP).
3. Commit changes.
4. Откройте вкладку Actions -> Build Busik APK.
5. Дождитесь зелёной галочки, откройте запуск workflow и скачайте artifact Busik-APK.
6. Распакуйте artifact ZIP — внутри будет app-debug.apk.

Название приложения: Busik. Пакет: com.busik.game.
